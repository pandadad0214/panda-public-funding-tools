# Panda Public Funding Tools

Focused MCP server for US federal money, filings, and safety monitors.

## When to use
- Find grants, federal contracts, or SBIR/STTR topics
- Pull SEC financials, clinical-trial leads, or Federal Register notices
- Check product recalls or decode a VIN for recalls

## When not to use
- Scholarly citations / literature → `panda-research-tools`
- Sales leads / enrichment → `panda-leads-tools`
- Site, email, or agent safety → `panda-web-security-tools`

## Notes
- Requires `APIFY_TOKEN` (free Apify token). Each tool starts one Apify Actor run billed to that account.
- Prefer one or two inputs first; read the tool `summary` / `agentSummary` before widening.
